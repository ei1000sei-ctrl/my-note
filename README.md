# my-note

えい先生（元ポンコツ教師）の note 記事のバックアップです。

教員23年の経験をもとに、若手教員の「授業・学級・働き方」を整えるヒントを発信しています。

- note: https://note.com/ei__sensei

## 記事の更新方法

```sh
python3 scripts/fetch_note.py
```

note から全記事を取得して `articles/` に Markdown で保存し、下の一覧を更新します。有料記事は無料部分のみ保存されます。
